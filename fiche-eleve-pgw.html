Ton application compagnon pour observer la Paris Games Week avec un regard d’informaticien : derrière les jeux, repère les algorithmes, les données, les réseaux, les technologies et les métiers.

Pourquoi cette application ?

La Paris Games Week n’est pas seulement un lieu où l’on joue. Chaque démonstration mobilise de l’informatique : calculs, structures de données, bases de données, échanges réseau, moteurs de jeu, sécurité, intelligence artificielle et interfaces.

PGW NSI Quest t’aide à transformer la visite en enquête : tu observes ce qui est visible à l’écran et tu cherches à comprendre ce qui se passe derrière.

Le but n’est pas d’écrire le plus possible. Une observation précise, reliée à une notion de NSI, vaut mieux qu’une réponse longue et vague.

Mode d’emploi

1
Ouvre PGW NSI Quest

Scanne le QR code ou utilise le lien fourni.

2
Relie ta visite

Appuie sur « Relier cette visite » puis saisis le code donné par ton professeur, ton pseudo et ta classe.

3
Commence la Mission 01

Les missions suivantes se débloquent progressivement. Tes réponses sont sauvegardées sur ton appareil.

4
Observe avant de répondre

Utilise le salon comme source : stands, écrans, affiches, échanges avec les exposants et démonstrations.

5
Vérifie l’envoi avant de partir

Ne ferme l’application qu’après le message vert « ✓ Données envoyées · tu peux quitter ».

Accès élève

Scanne → ouvre → relie ta visite

Le code de session est communiqué par ton professeur.

Si le réseau fonctionne mal

Continue ton activité. Les réponses sont enregistrées localement puis synchronisées lorsque la connexion revient.

À éviter : navigation privée, changement de navigateur, suppression des données du site ou changement de téléphone en cours de visite.

Avant de quitter le salon

Le contrôle final est simple :

✓ Données envoyées · tu peux quitter

Si ce message n’apparaît pas, garde l’application ouverte et préviens ton professeur.
