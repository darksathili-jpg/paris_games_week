- Aucun titre, numéro, XP, badge, bouton ou faux cadre.
- Une scène illustrative par mission.
- Même direction artistique sur les 6 scènes.
- Zone sûre centrale pour le cadrage mobile/desktop.
- Master haute définition conservé hors compression destructive.
- Export Web : AVIF/WebP + fallback si nécessaire.
- Aucun asset n'est branché à la preview tant qu'il n'a pas passé le contrôle visuel.
