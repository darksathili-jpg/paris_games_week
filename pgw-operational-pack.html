1 · Démarrage — 2 min

  1. Supabase : Anonymous Sign-Ins activé ; limite 60/h.
  2. Ouvrir le cockpit → session PGW NSI 2026 → Inscriptions ouvertes.
  3. Élèves : QR → code PGW26 + pseudo + classe.
  4. Quand tous sont reliés : Fermer les inscriptions. La synchronisation reste active.

2 · Réseau mauvais

  • Continuer : les réponses restent enregistrées localement.
  • Ne pas effacer les données navigateur, changer de navigateur ou passer en privé.
  • Laisser la même page ouverte jusqu'au retour du réseau.
  • Erreur 429 : attendre puis réessayer ; ne pas recréer des comptes.

3 · Changement de téléphone

  1. Ancien appareil : obtenir d'abord ✓ Données envoyées · tu peux quitter.
  2. Réouvrir temporairement les inscriptions si nécessaire.
  3. Nouveau téléphone : QR + PGW26 + pseudo distinct, ex. Prénom-2.
  4. Refermer les inscriptions. L'ancien et le nouveau profil seront consolidés dans le CSV si besoin.
Sans synchronisation préalable, les réponses uniquement locales de l'ancien téléphone ne sont pas récupérables depuis Supabase.

4 · Avant de quitter le salon

  1. Cockpit → Contrôle de fin de visite.
  2. Objectif : À vérifier avant départ = 0.
  3. Chaque élève doit voir ✓ Données envoyées · tu peux quitter.
  4. Sinon : réseau actif + application ouverte, puis ↻ Actualiser le cockpit.

5 · Export final

  1. Fermer les inscriptions → ↻ Actualiser → vérifier qu'il ne reste aucun élève à contrôler.
  2. Cliquer Exporter CSV et ouvrir immédiatement pgw-nsi-2026-2026-10-23.csv.
  3. Vérifier la présence des élèves/réponses puis conserver deux copies sur deux emplacements distincts.
Règle RC1 : aucune modification du logiciel sur place sauf défaut P0/P1 reproductible. En cas de problème réseau, priorité à la sauvegarde locale puis à la synchronisation avant départ.
